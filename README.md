# Polo Optimizer

โปรแกรมดูแลคอม Windows แบบเปิดโปรแกรมเดียวจบ ทำไว้สำหรับคนที่ใช้คอมไม่เก่ง
ลงแอป หาไดรเวอร์ ล้างไฟล์ขยะ ปรับเครื่องเล่นเกม และแก้ปัญหาที่เจอบ่อยได้ในที่เดียว
ใช้ได้ทั้งภาษาไทยและอังกฤษ (กดเปลี่ยนที่มุมล่างของเมนูซ้าย) และทุกปุ่มมีคำอธิบายบอกว่ากดแล้วจะเกิดอะไร

ทำด้วย Python + customtkinter (หน้าตา) + psutil (อ่านการใช้งาน CPU/RAM/ดิสก์) + Pillow (วาดโลโก้และวงแหวนเกจ)
แล้วแปลงเป็นไฟล์ .exe ไฟล์เดียวด้วย PyInstaller เครื่องที่เอาไปใช้ไม่ต้องลง Python

## วิธีสร้างไฟล์ .exe

1. ลง Python 3.12 จาก https://www.python.org/downloads/
   ตอนติดตั้งต้องติ๊ก **Add python.exe to PATH**
2. ดับเบิลคลิก `build.bat` แล้วรอประมาณ 1-3 นาที (ครั้งแรกจะนานกว่านั้นเพราะต้องโหลดไลบรารี)
3. ได้ไฟล์ `dist\PoloOptimizer.exe` เอาไฟล์นี้ไฟล์เดียวไปใช้เครื่องไหนก็ได้

สิ่งที่ `build.bat` ทำ
- หา Python 3.12 ก่อน ถ้าไม่มีก็ใช้ Python ตัวที่มีในเครื่อง
- สร้างโฟลเดอร์ `.venv` แยกไว้ ไลบรารีจะไม่ไปปนกับ Python หลักของเครื่อง
- ลงไลบรารีตาม `requirements.txt`
- ถ้ายังไม่มี `logo.png` จะสร้างโลโก้ใหม่ (`icon.ico` + `logo.png`) ด้วย `make_icon.py`
- เรียก PyInstaller ด้วย `--onefile --windowed --uac-admin --icon icon.ico --collect-all customtkinter`

หลัง build จะมีโฟลเดอร์ `build`, `.venv` และไฟล์ `PoloOptimizer.spec` เกิดขึ้นมา เป็นไฟล์ชั่วคราวของการ build ลบทิ้งได้

## สร้างตัวติดตั้ง (Setup.exe) ไว้แจกให้คนอื่นโหลด

1. ดับเบิลคลิก `build_setup.bat` (ถ้ายังไม่มี `dist\PoloOptimizer.exe` จะเรียก `build.bat` ให้ก่อน และถ้าเครื่องยังไม่มี Inno Setup จะลงให้ผ่าน winget)
2. ได้ไฟล์ `release\PoloOptimizer-Setup-<เวอร์ชัน>.exe` (เลขเวอร์ชันอ่านจาก `APP_VERSION` ใน `main.py`)

ตัวติดตั้งใช้โปรแกรมแบบโฟลเดอร์ (PyInstaller `--onedir` อยู่ใน `dist_setup\`) ไม่ใช่ไฟล์เดียว เพราะไม่ต้องแตกไฟล์ตัวเองลง Temp ทุกครั้งที่เปิด จึงเปิดเร็วกว่าและแอนติไวรัสเตือนผิด ๆ น้อยกว่า ส่วน `dist\PoloOptimizer.exe` แบบไฟล์เดียวยังมีไว้ใช้แบบพกพา

ตัวติดตั้งทำอะไรบ้าง
- หน้าติดตั้งเป็นภาษาไทย (เลือกอังกฤษได้) มีรูปตกแต่งโทนน้ำเงิน-ดำจาก `make_setup_images.py`
- ลงโปรแกรมไว้ที่ `C:\Program Files\Polo Optimizer` สร้างไอคอนใน Start Menu และบน Desktop (ติ๊กเลือกได้)
- เพิ่มรายการใน Settings > Apps ถอนการติดตั้งได้ตามปกติ ลงเวอร์ชันใหม่ทับได้ไม่ขึ้นซ้ำ (เพราะ `AppId` ใน `setup.iss` คงที่)
- หน้าสุดท้ายมีช่องติ๊ก "เปิดโปรแกรมเลย"

| ไฟล์ | หน้าที่ |
|---|---|
| `setup.iss` | สคริปต์ตัวติดตั้งของ Inno Setup (ต้องบันทึกเป็น UTF-8 แบบมี BOM เพราะมีภาษาไทย) |
| `build_setup.bat` | ดับเบิลคลิกแล้วได้ Setup.exe |
| `make_setup_images.py` | วาดรูปด้านซ้ายและโลโก้เล็กของหน้าตัวติดตั้ง |

ถ้าแก้โค้ดแล้วอยากได้ตัวติดตั้งใหม่: รัน `build.bat` ก่อน แล้วค่อยรัน `build_setup.bat` (ถ้าเปลี่ยนเวอร์ชัน แก้ `APP_VERSION` ใน `main.py`)

## รันจากโค้ดโดยตรง (ตอนแก้โค้ด)

```
.venv\Scripts\python.exe main.py
```

โปรแกรมจะเด้งหน้าต่าง UAC ขอสิทธิ์ Admin เอง ถ้าอยากรันแบบไม่ขอสิทธิ์ (บางปุ่มจะใช้ไม่ได้) ให้ใส่ `--no-elevate` ต่อท้าย

| `make_icon.py` | วาดโลโก้ (ตัว P + สายฟ้า) เป็น `icon.ico` และ `logo.png` (ใช้แค่ตอน build) |

| `build.bat` | ดับเบิลคลิกแล้วได้ `dist\PoloOptimizer.exe` |

## เมนู 9 หน้า

0. **เริ่มต้น** แบนเนอร์ชื่อโปรแกรม, ผู้พัฒนา, วิธีใช้ 4 ขั้นตอน, ช่องฟีเจอร์ที่กดไปหน้านั้นได้ และคำสัญญาเรื่องความปลอดภัย (เปิดโปรแกรมครั้งแรกจะเริ่มที่หน้านี้)
1. **หน้าแรก** คะแนนสุขภาพเครื่องพร้อมปุ่มแก้ทีละข้อ, สเปกเครื่อง, เกจวงแหวน CPU/RAM/ดิสก์ (อัปเดตทุก 1.5 วินาที ดิสก์เกิน 90% ขึ้นสีแดง), ปุ่มดูแลเครื่องคลิกเดียว, ปุ่มสร้างจุดคืนค่า
2. **ผู้ช่วย AI** เล่าอาการด้วยคำของตัวเอง โปรแกรมตรวจเครื่องจริงก่อนตอบทุกครั้ง แล้วตอบพร้อมปุ่ม "ทำเลย" และปุ่มคำถามต่อ
3. **ติดตั้งแอป** การ์ดแอปพร้อมโลโก้ ช่องค้นหา ตัวกรองติดตั้งแล้ว/ยังไม่ติดตั้ง (ตรวจจาก `winget export`) ติดตั้งทีละตัวหรือติ๊กหลายตัวแล้วติดตั้งทีเดียว
4. **ไดรเวอร์** ปุ่มไปเว็บไดรเวอร์การ์ดจอ/เครื่อง/เมนบอร์ด (ASUS พาไปหน้าโหลดไดรเวอร์ของรุ่นนั้นตรง ๆ), อุปกรณ์ที่มีปัญหาพร้อมลิงก์โหลด, Windows Update
   - อ่าน Hardware ID ของอุปกรณ์ที่มีปัญหา (เช่น `PCI\VEN_1022&DEV_1649`) แล้วรู้ว่าเป็นของค่ายไหน (`VEN_1022` = AMD, `VEN_8086` = Intel, `VEN_10DE` = NVIDIA, `VEN_10EC` = Realtek)
   - จัดกลุ่มอุปกรณ์ที่แก้ด้วยไดรเวอร์ตัวเดียวกัน เช่นอุปกรณ์ชิปเซ็ต AMD หลายตัว -> ปุ่มโหลด AMD Chipset Driver ของชิปเซ็ตที่ตรงกับเมนบอร์ด (เดาจากชื่อรุ่น เช่น PRIME B650M-A II -> B650 / AM5)
   - ทุกอุปกรณ์มีปุ่ม "หาไดรเวอร์ตัวนี้" ค้นด้วย Hardware ID ใน Microsoft Update Catalog (เว็บทางการของ Microsoft)
5. **ล้างเครื่อง** สแกนไฟล์ขยะแยกหมวดก่อนลบ และปุ่มคืน RAM
6. **ปรับเล่นเกม** สวิตช์ปรับแต่ง 3 ตัว และเลือกแผนพลังงาน
7. **โปรแกรมเปิดพร้อมเครื่อง** สวิตช์เปิด/ปิดแต่ละโปรแกรม
8. **แก้ปัญหา** ซ่อมไฟล์ระบบ, รีเซ็ตเน็ต, รีสตาร์ททาสก์บาร์, สุขภาพดิสก์ และการ์ด "Windows มีปัญหาหนัก / อยากเริ่มใหม่" เรียงจากเบาไปหนัก: คืนค่าเริ่มต้น Windows (ย้อนทุกอย่างที่โปรแกรมนี้ปรับ รวมถึงเปิดโปรแกรมเปิดพร้อมเครื่องที่โปรแกรมนี้เคยปิด), ย้อนกลับไปจุดคืนค่า (System Restore) และ Reset this PC

## ส่วนอื่น ๆ ของหน้าจอ

- **หน้าโหลด** ตอนเปิดโปรแกรมจะมีหน้าโหลดโลโก้ + ชื่อโปรแกรม ประมาณ 2 วินาที ระหว่างนั้นสร้างหน้าจอหลักไปด้วย (ปิดได้ด้วย `--no-splash`)
- **แถบค้นหาด้านบน** (Ctrl+K) ค้นได้ทั้งหน้า งานที่กดทำได้ และแอป ด้วยภาษาไหนก็ได้ ถ้าไม่เจอ กด Enter จะส่งข้อความเป็นคำถามให้ผู้ช่วย AI
- **โทนสีและไอคอน** โทนดำ-น้ำเงิน ใช้น้ำเงินเป็นสีเน้นสีเดียว (เขียว/เหลือง/แดง ใช้บอกสถานะเท่านั้น) ไอคอนเป็นเส้นบางจากฟอนต์ Segoe MDL2 Assets ที่มากับ Windows (ชุดเดียวกับหน้า Settings) ในโค้ดเขียนเป็นอีโมจิไว้ให้อ่านง่าย แล้ว `emoji_image()` ใน `ui_kit.py` แปลงเป็นไอคอนเส้นตามตาราง `ICONS` และระบายสีตามที่ใช้ (ปุ่ม = สีตัวอักษร, หัวข้อ = น้ำเงิน, เมนู = เทา/น้ำเงินตอนเลือก)
- **ข้อมูลผู้พัฒนา** แก้ได้ที่ `APP_AUTHOR` และ `APP_AUTHOR_DETAIL` ด้านบนของ `main.py`

## ตั้งค่าผู้ช่วย AI (ไม่บังคับ)

1. เข้า https://aistudio.google.com/apikey (หรือกดปุ่ม "ขอ API key ฟรี" ในหน้า AI) แล้วสร้าง key
2. เอา key มาวางในช่อง Gemini API key แล้วกด "บันทึก"
3. ชื่อโมเดลเริ่มต้นคือ `gemini-2.5-flash` ถ้า Google เลิกใช้ชื่อนี้ (จะขึ้นว่าไม่พบโมเดล) ให้ดูชื่อใหม่ใน AI Studio แล้วเปลี่ยนในช่อง "โมเดล"

ทุกครั้งที่ถาม โปรแกรมจะตรวจเครื่องก่อน (ใช้เวลาประมาณ 5-8 วินาที) แล้วตอบจากผลตรวจนั้น

- **โหมด Gemini** (มี key) ถามอะไรก็ได้แบบอิสระ AI ได้ผลตรวจทั้งหมดและบทสนทนาก่อนหน้าไปด้วย ถ้าข้อมูลไม่พอจะถามกลับ
- **โหมดออฟไลน์** (ไม่มี key หรือไม่มีเน็ต) หาว่าคำถามตรงกับปัญหาแบบไหน (มีราว 20 แบบ เช่น ช้า, เกมกระตุก, เน็ต, ปิง, จอฟ้า, เสียง, แบต, ร้อน, ไวรัส) แล้วยกผลตรวจที่เกี่ยวข้องขึ้นมาตอบ ถ้าพิมพ์ว่า "ยังไม่หาย" จะได้วิธีขั้นต่อไป ถ้าคำถามไม่ตรงหัวข้อไหนเลย จะสรุปสิ่งผิดปกติที่ตรวจเจอในเครื่องให้แทน

## กฎความปลอดภัยที่โปรแกรมทำตาม

- ไม่ปิด Windows Defender, ไม่ปิด Windows Update, ไม่แตะ mitigations หรือ Services ของระบบ
- ลบได้เฉพาะโฟลเดอร์แคช/ไฟล์ชั่วคราวที่กำหนดไว้ใน `cleaner.py` เท่านั้น และมีกันพลาดหลายชั้น
  - ลบแค่ของข้างในโฟลเดอร์แคช ไม่ลบตัวโฟลเดอร์
  - ไม่เดินเข้า junction/symlink (เพราะอาจชี้ไปที่ไฟล์จริงของผู้ใช้)
  - ไฟล์ใน Temp ที่อายุไม่ถึง 1 วันจะไม่ลบ เผื่อเป็นของโปรแกรมที่กำลังติดตั้งอยู่
  - ข้ามโฟลเดอร์ที่ตัว .exe แตกไฟล์ตัวเองไว้ใน Temp
- ข้อมูลออกนอกเครื่องแค่ตอนผู้ใช้กดส่งคำถามในโหมด Gemini และเขียนบอกไว้ในหน้า AI แล้ว
- AI สั่งทำอะไรเองไม่ได้ ตอบได้แค่ข้อความกับรหัส action ที่อยู่ในรายการอนุญาต ผู้ใช้ต้องกด "ทำเลย" เองทุกครั้ง
- แอปติดตั้งผ่าน winget เท่านั้น ไดรเวอร์พาไปเว็บผู้ผลิตโดยตรงเท่านั้น

## เรื่องที่น่าเอาไปอธิบาย

**ทำไมหน้าต่างไม่ค้าง** งานที่ใช้เวลานานรันใน thread แยกผ่าน `App.run_task()` แต่ tkinter ไม่ให้ thread อื่นแก้หน้าจอตรง ๆ เลยให้ thread ฝากงานไว้ในคิว (`App.ui()`) แล้ว main thread ใช้ `.after(50, ...)` มาดึงงานจากคิวไปทำทุก 50 มิลลิวินาที

**ทำไมโปรแกรมไม่เด้งปิด** error ใน thread ถูกจับใน `run_task()`, error ในปุ่มถูกจับด้วย `report_callback_exception` ทั้งหมดไปแสดงที่แถบสถานะ และเก็บรายละเอียดไว้ใน `%APPDATA%\PoloOptimizer\error.log`

**ปิดโปรแกรมเปิดพร้อมเครื่องยังไง** ไม่ได้ลบออกจาก registry แต่เขียนค่า 12 byte ลงใน `StartupApproved\Run` (byte แรก 02 = เปิด, 03 = ปิด) ซึ่งเป็นที่เดียวกับที่ Task Manager ใช้ ผู้ใช้เลยเปิดกลับได้ทั้งในโปรแกรมนี้และใน Task Manager

**รู้ได้ยังไงว่าแอปมีอยู่แล้ว** winget คืนรหัส -1978335189 หรือ -1978335135 เมื่อแอปติดตั้งอยู่แล้ว แต่ Windows ส่งรหัสออกมาเป็นเลขไม่ติดลบ 32 บิต เลยต้องแปลงก่อน (ดู `to_signed32()` ใน `utils.py`)

**รู้ยี่ห้อการ์ดจอที่ยังไม่มีไดรเวอร์ได้ยังไง** การ์ดที่ไม่มีไดรเวอร์จะชื่อ "Microsoft Basic Display Adapter" แต่รหัส `PNPDeviceID` ยังมี Vendor ID อยู่ (VEN_10DE = NVIDIA, VEN_1002 = AMD, VEN_8086 = Intel)

**ทำไมต้องตัดบรรทัดภาษาไทยเอง** Tk บน Windows วาดข้อความเป็นท่อนละประมาณ 200 byte (ดู `MultiFontTextOut` ใน `tkWinFont.c` ของ Tk) ภาษาไทย 1 ตัวใช้ 3 byte ถ้าจุดตัดตกหน้าสระบนหรือวรรณยุกต์ มันจะหลุดออกมาเป็นวงกลมประ เลยเขียน `tk_safe()` จำลองจุดตัดของ Tk แล้วแทรกตัวอักษรล่องหน (zero-width space) หน้าพยัญชนะ ให้ Tk ไปตัดตรงนั้นแทน และเขียน `thai_wrap()` ตัดบรรทัดเองโดยไม่ตัดหน้าสระ/วรรณยุกต์

**คะแนนสุขภาพเครื่องคิดยังไง** เริ่มที่ 100 แล้วหักตามปัญหาจริง เช่น ไดรฟ์เต็มเกิน 90% หัก 20, ไฟล์ขยะเกิน 5 GB หัก 15, อุปกรณ์ไม่มีไดรเวอร์หักตัวละ 5 (ไม่เกิน 20) ดูได้ใน `health.py`

**AI รู้ได้ยังไงว่าเน็ตเสียตรงไหน** `diagnostics.network_check()` ทดสอบทีละชั้น: มี IP ไหม → ปิงเราเตอร์ได้ไหม → ปิง 1.1.1.1 ได้ไหม → แปลงชื่อเว็บได้ไหม (DNS) ชั้นแรกที่พังคือจุดที่เสีย เช่น ปิง 1.1.1.1 ได้แต่ DNS ไม่ได้ แปลว่าเน็ตใช้ได้แต่ DNS มีปัญหา

**AI รู้สาเหตุจอฟ้าได้ยังไง** อ่าน Event Log ของ Windows (event 1001 จาก WER-SystemErrorReporting) ซึ่งมีรหัสจอฟ้า (bugcheck code) อยู่ แล้วเทียบกับตารางรหัสที่เจอบ่อยใน `diagnostics.BUGCHECKS`

**เปลี่ยนภาษายังไง** ทุกข้อความเขียนคู่กันไว้ เช่น `tr("ล้างไฟล์ขยะ", "Clean junk")` พอกดเปลี่ยนภาษา โปรแกรมจะลบหน้าจอเดิมแล้วสร้างใหม่ทั้งหมด งานเบื้องหลังที่ยังค้างอยู่จะมีเลขรุ่นของหน้าจอติดไว้ ถ้าเสร็จหลังเปลี่ยนภาษาจะไม่ไปแตะหน้าจอเก่าที่ถูกลบไปแล้ว

**คืน RAM ได้ผลจริงไหม** ได้ผลชั่วคราว โปรแกรมจะดึง RAM กลับไปใช้เมื่อต้องการ ช่วยได้ตอน RAM ใกล้เต็ม แต่ไม่ได้ทำให้เครื่องเร็วขึ้นถาวร ในโปรแกรมก็เขียนบอกผู้ใช้ไว้ตรง ๆ

## ใช้บนเครื่องคนอื่น

- **ข้อมูลโปรแกรมในไฟล์ .exe** `make_version_info.py` สร้าง `version_info.txt` ให้ PyInstaller ฝังชื่อโปรแกรม ผู้พัฒนา และเวอร์ชันลงในไฟล์ (ดูได้ที่ Properties > Details) ไฟล์ที่มีข้อมูลพวกนี้ดูน่าเชื่อถือกว่าในสายตาแอนติไวรัส
- **จอทุกขนาด** ตอนเปิด โปรแกรมอ่านพื้นที่ใช้งานจริงของจอ (ไม่รวมทาสก์บาร์ และคิดค่าขยายจอของ Windows แล้ว) แล้วตั้งขนาดหน้าต่างให้พอดี ถ้าจอเตี้ยกว่า 800 จะย่อเมนูซ้าย (ซ่อนคำอธิบายใต้ชื่อ) และพับส่วนตั้งค่า Gemini ในหน้า AI ไว้ ความกว้างข้อความและจำนวนคอลัมน์ในหน้าเริ่มต้นปรับตามความกว้างหน้าต่าง (ดู `_fit_to_screen()` ใน `main.py` และ `TEXT_WIDTH` ใน `ui_kit.py`)
- **แจ้งปัญหา** หน้าแก้ปัญหามีปุ่มเปิดโฟลเดอร์ที่มี `error.log` คนที่เจอปัญหาส่งไฟล์นี้มาให้ผู้พัฒนาได้
- **จอฟ้า "Windows protected your PC" (SmartScreen)** จะขึ้นกับไฟล์ที่ไม่ได้เซ็นชื่อดิจิทัล ให้กด More info > Run anyway ถ้าอยากให้หายจริงต้องซื้อใบรับรอง code signing ถ้าแอนติไวรัสจับผิด ส่งไฟล์ให้ Microsoft ตรวจได้ที่ https://www.microsoft.com/en-us/wdsi/filesubmission

## หมายเหตุ

- รองรับ Windows 10 และ 11 (64 บิต)
- winget มากับ Windows 10 รุ่นใหม่และ Windows 11 ถ้าเครื่องไหนไม่มี หน้าติดตั้งแอปจะมีปุ่มพาไปลง App Installer จาก Microsoft Store
- โปรแกรมที่เป็น .exe ไฟล์เดียวและขอสิทธิ์ Admin บางครั้งโดนแอนติไวรัสเตือน (false positive) เพราะ PyInstaller แตกไฟล์ลง Temp ตอนเปิด
